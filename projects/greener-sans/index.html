From a logo to a font

I started drawing the GREENER logo when I was fourteen and have redrawn it a few times since. Every version only ever had six letters in it, so I wanted to see what the rest of the alphabet would look like if it followed the same rules.

The G is taken straight from the logo. Everything else is built from what the logo already does: very heavy stems, counters squeezed down to thin slits, perfectly round bowls and flat, square ends.

1Read the logo

Stems a quarter of the letter height, counters an eighth, bowls closed to a slot with a rounded end.

2Make the rules

Straight letters stay square. Round letters are near-perfect circles. Bowls in B, P and R become slots, like the logo's R.

3Build the rest

Every capital, number and the core punctuation, all following the same rules so they sit together.
